# Drone Propeller Thrust Calculator

Estimates total drone thrust and thrust-to-weight ratio from the number of motors and the thrust produced by each motor.

## Run

```bash
python thrust_calculator.py
```

## Skills demonstrated

- Writing reusable Python functions
- Working with units and engineering ratios
- Input validation
- Turning an engineering question into a small program

This is an educational estimate. Real aircraft performance depends on propellers, battery voltage, air density, motor efficiency, and flight conditions.
